خلّ Claude يفحص الواي فاي

بدل ما تتصل بالشركة: Claude يفحص الشبكة، يلقى وش اللي يبطّئها، ويعطيك الحل خطوة بخطوة. وقبل أي تغيير ياخذ نسخة احتياطية، وعندك أمر يرجّع كل شي مثل ما كان.

🔍 فحص←💾 نسخة احتياطية←🛠️ إصلاح←📊 قبل / بعد

وش تحتاج

Claude على الكمبيوترClaude Code، أو Claude ديسكتوب مع صلاحية تشغيل الأوامر
لابتوب على نفس الواي فايWindows أو Mac
صفحة الراوترغالباً 192.168.1.1، واسم المستخدم والباسورد تحت الراوتر

الخطوات

  1. سوّ سبيد تست

    افتح speedtest.net وسجّل السرعة قبل. بتحتاجها عشان تقارن بعدين.

  2. برومبت الفحص

    الصقه في Claude. هذا البرومبت يقرأ بس، ما يغيّر شي، ويحفظ نسخة احتياطية من إعداداتك في مجلد wifi-backup على سطح المكتب.

    You are my network assistant. My WiFi feels slow. Help me find out why.

RULES:
- First, detect my OS (Windows or macOS) and use the right commands.
- Read-only first: do NOT change any setting until I say "yes".
- Before ANY change, save a backup of my current settings to a folder
  on my Desktop called "wifi-backup" (current DNS servers, IP config,
  WiFi interface details, WiFi adapter settings). Tell me the path.

DIAGNOSE:
1. My current connection: band (2.4 / 5 GHz), channel, signal strength,
   link speed.
2. Scan nearby networks and tell me which channels are crowded.
3. Compare my current DNS response time with 1.1.1.1 and 8.8.8.8.
4. Ping my router and 1.1.1.1 for 20 seconds: show latency and packet loss.

Then give me the top 3 fixes ranked by expected impact, in simple Arabic,
and say which ones I do on the laptop and which ones in the router page.

  3. طبّق حل واحد بس

    Claude بيعطيك أفضل ٣ حلول. جرّب واحد، وقارن، وبعدها انتقل للثاني.

    Apply fix number [1/2/3] only.
- Confirm the backup in Desktop/wifi-backup exists first.
- Show me the exact command before you run it and wait for my "yes".
- After the change, run the same tests again and show before/after in a table.

  4. سبيد تست مرة ثانية

    قارن الرقم الجديد بالقديم. إذا ما تحسّن، رجّع الإعداد وجرّب الحل اللي بعده.

↩️ رجّع كل شي مثل ما كان

إذا ما عجبتك النتيجة، أو صار أي شي غريب، الصق هذا في Claude:

Undo everything you changed.
Restore my network settings exactly as they were, using the backup in
Desktop/wifi-backup (DNS, IP config, adapter settings).
Then run the tests again and confirm everything matches the backup.

ولو تبي ترجّع الـ DNS يدوي بدون Claude:

Windows: افتح Command Prompt كـ Administrator

netsh interface ip set dns name="Wi-Fi" source=dhcp
ipconfig /flushdns

Mac: Terminal

networksetup -setdnsservers Wi-Fi empty
sudo dscacheutil -flushcache
إعدادات الراوتر: Claude ما يدخل الراوتر بنفسه. قبل ما تغيّر أي شي هناك، صوّر الشاشة. ولو خرّبت شي، ارجع للصورة وحط القيم نفسها.

أشهر الأشياء اللي يلقاها

المشكلةالحل
متصل على 2.4GHzاتصل بشبكة الـ 5GHz، أسرع بكثير لو كنت قريب من الراوتر
القناة زحمةمن صفحة الراوتر غيّر القناة للأقل زحمة اللي يقترحها Claude
DNS بطيءغيّره لـ 1.1.1.1 أو 8.8.8.8
الإشارة ضعيفةغيّر مكان الراوتر: مرتفع، في النص، بعيد عن الجدران والميكرويف
الراوتر شغّال من زمانرستارت للراوتر، وحدّث الـ firmware
للأمانة: Claude ما يزيد سرعة الباقة اللي دافع عليها. هو يشيل اللي يبطّئك عشان توصل لأقرب سرعة لباقتك. ولو السرعة واطية حتى والكيبل موصول، فالمشكلة من الشركة.

نصايح أمان

  • لا تعطيه باسورد الراوتر. إنت تدخل صفحة الراوتر وتغيّر بنفسك.
  • غيّر شي واحد كل مرة، عشان تعرف وش اللي فرق.
  • اقرأ الأمر قبل ما تقول yes. البرومبت يجبره ينتظر موافقتك.
